# 한주 식단 — 독립형 오프라인 안드로이드 APK

이 프로젝트는 외부 사이트를 표시하지 않습니다. 달력과 식단 관련 HTML/CSS/JS 파일이 APK 내 `assets`에 직접 포함되며 인터넷 권한을 선언하지 않습니다.

## APK 만들기 (회사 PC에 프로그램 설치 불필요)
1. GitHub에서 새 비공개(private) 저장소를 생성합니다.
2. 이 ZIP 파일을 풀어서 **안에 들어 있는 파일/폴더 자체**를 GitHub 저장소에 업로드합니다. `.github/workflows/build-apk.yml`도 포함되어야 합니다. 웹 업로드에서 숨김 폴더 `.github`가 누락되지 않도록 확인합니다.
3. `Actions` → `Build offline Android APK` → `Run workflow`를 누릅니다. 또는 main 브랜치에 변경사항을 올리면 자동 실행됩니다.
4. Actions 실행 완료 후 해당 실행 페이지의 `Artifacts` → `HanjuMeal-Offline-APK`를 다운로드하고 ZIP 안의 `app-debug.apk`를 갤럭시에서 설치합니다.

GitHub Actions는 GitHub 계정 설정에 따라 활성화가 필요할 수 있고 외부 네트워크 및 빌드 의존성 내려받기가 가능합니다. 회사의 정책을 준수하세요.

## 데이터 주의
- 기존 Netlify 사이트의 식단 기록과 APK의 기록은 **별개 저장 공간**입니다.
- 기존 웹앱에서 설정 → 기록 백업하기(.json) → 이 APK에서 설정 → 백업 파일 불러오기를 하세요.
- 설치한 APK의 앱 데이터 삭제/앱 제거 시 로컬 기록이 사라질 수 있으므로 정기 백업하세요.
- 이 프로젝트는 디버그 APK를 만듭니다. 개인 테스트 설치용입니다. 재빌드 시 서명 키가 바뀌어 설치 앱 위에 업데이트가 불가능할 수 있습니다. 버전 업데이트용으로는 동일한 릴리스 서명 키 관리가 필요합니다.
